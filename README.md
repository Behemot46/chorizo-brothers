# גבי ושחר - האחים צ'וריסו - המרדף אחרי הנקניקייה

Chorizo Brothers: a mobile arcade highway game. One HTML file, Three.js (r128 from cdnjs), no build step.
Hebrew UI (RTL). Live: https://chorizo-brothers.vercel.app

## Play
Swipe or tap the sides to change lane, tap the middle for nitro. Corner buttons: missile, electric shock, chorizo missile.
Collect glowing sausage coins and sausage bonuses, buy vehicles and upgrades in the garage.

## Develop
Open `index.html` in a browser. Tests (Playwright + Chromium, real touch events): see `tests/README.md`.
